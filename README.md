# Organic Holi Website (Localhost Demo)

## Run on localhost
1) Unzip the folder.
2) Open Terminal in the unzipped folder.
3) Run:

### Option A (Python)
python -m http.server 8000

Now open: http://localhost:8000

### Option B (VS Code)
Use "Live Server" extension.

## Customize
- Update text in: index.html, about.html, products.html, contact.html
- Update styles in: assets/css/style.css
- Replace banners in: assets/img/
